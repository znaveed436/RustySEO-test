## Project overview

RustySEO is a Tauri 2 desktop SEO/GEO toolkit.

Frontend:
- Next.js
- React
- TypeScript
- Tailwind/Mantine/Radix-style components
- Zustand stores

Backend:
- Rust
- Tauri 2 commands
- SQLite/rusqlite
- Crawling, log analysis, exports, integrations, AI tooling
